Hangman-Game
A classic Hangman game written in Python.

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![MIT License](https://img.shields.io/badge/License-MIT-yellow.svg)

Hangman-Game is a fun, text-based implementation of the popular word-guessing game, Hangman. It's designed for anyone who wants to play a quick game of Hangman directly from their terminal. This project is built entirely in Python, making it easy to run and modify.

*   Randomly selected words from a predefined list.
*   Tracks player guesses and displays the hangman figure progressively.
*   Provides feedback on correct and incorrect guesses.
*   Allows players to guess the word within a set number of attempts.

## Installation

```bash
git clone https://github.com/smoke-mp3/Hangman-Game.git
cd Hangman-Game
pip install -r requirements.txt
```

## Quick Start

To play the game, simply run the main Python script from your terminal:

```bash
python hangman.py
```
